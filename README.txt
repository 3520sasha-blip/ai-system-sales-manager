# UI/UX Design Submission: PRODUCT PAGE — SALES MANAGER

Professional test assignment submission for the **Trainee/Junior Web Designer** position at **AI Business Systems (Denmark)**.

## 1. Project Overview & Scope
*   **Target Page:** Product Internal Page — **"SALES MANAGER"**
*   **Target URL Mapped:** `/products/sales-manager/`
*   **Design Framework:** Figma (Strict Vector Architecture & Auto Layouts)
*   **Typography Scale:** Montserrat Family (Google Fonts Standard Open-Source License)
*   **Core Color Palette:** Dark Ambient Mode (#050A07), Light Typography (#EEF4EF, #B9C7BE), System Accent Emerald (#3DDC5A, Hover State: #6CF08A).

## 2. Repository Directory Structure
The repository is strictly structured in full compliance with the technical acceptance checklist:
*   `previews/` — High-fidelity 4x crisp responsive renders (Desktop 1440px, Mobile 390px layout views).
*   `sources/` — Master production file (`.fig` format) with native interactive components, auto-layouts, and connected typography styles.
*   `assets/` — High-resolution source backdrops generated via Luma AI Nano Banana engine for custom architectural window environments.

## 3. Core UX/UI Decisions
*   **Anti-Scale Architecture:** No Figma Scale (K-tool) transformations were used on live text blocks. All cards dynamically stretch up to 584px using responsive `Fill container` guidelines, maintaining strict typography hierarchy.
*   **Content Rigor:** Zero copy mutations, deletions, or structural modifications. All text blocks exactly mirror the provided configuration file.
*   **Interactive Integrity:** Contact buttons in the footer are bound to live functional `mailto:`, `tel:`, and verified API endpoints.
